Supported field types

string, number, integer, boolean, and array of a scalar type. Optional per-field enum, format (email/uuid/date/date-time), minLength/maxLength, minimum/maximum, and a length-capped pattern. Unknown fields on write are rejected (no additionalProperties: true).

Limits (free plan)

  • 3 live projects, 5 collections each, 500 records per collection
  • 120 requests/min per project, 20KB request bodies
  • projects expire after 14 days of being created
